# FreePlayer (macOS)

مشغّل موسيقى محلي. دون اتصال بالشبكة، دون تسجيل دخول، دون جمع أي بيانات. موسيقاك تبقى على قرصك، بهيكل مجلداتك الخاص.

تنفيذ أصلي لنظام macOS (SwiftUI + AppKit)، دون اعتماديات خارجية (أطر النظام + SQLite فقط).

## الصيغ المدعومة

MP3, FLAC, WAV, OGG, M4A, AAC, AIFF (قابلة للفك بواسطة AVFoundation)

## المزايا

- **الاستيراد والمكتبة** : استخراج تلقائي للبيانات الوصفية (العنوان، الفنان، الألبوم، السنة، النوع، رقم المقطع، معدل البت، معدل العينة، القنوات)؛ تُنسخ الملفات أو تُربط رمزيًا بهيكل فنان/ألبوم (الوضع قابل للاختيار في الإعدادات)
- **إحصاءات الاستماع** : تُسجَّل كل جلسة في SQLite (البداية/النهاية، المدة، النسبة) — إجمالي الوقت، عدد التشغيلات، أفضل 10 مقاطع/فنانين، إحصاءات يومية لآخر 30 يومًا
- **قوائم التشغيل** : إنشاء/إعادة تسمية/حذف، إضافة فردية أو دفعة، تحرير القائمة
- **كلمات LRC** : كشف تلقائي أو ربط يدوي لملفات .lrc؛ ترميزات UTF-8 ← GB18030 ← Shift_JIS
- **ReplayGain** : ضبط تلقائي لمستوى الصوت عبر الوسوم
- **الأغلفة** : استخراج الصور المضمّنة عند الاستيراد إلى مجلد .covers الخاص بالألبوم
- **مفاتيح الوسائط / شريط القوائم** : مفاتيح النظام تشغيل/إيقاف/السابق/التالي، معلومات في Control Center، تحكم من أيقونة شريط القوائم؛ إغلاق النافذة يخفيها في الشريط ويواصل التشغيل
- **المرئيات** : راسم ذبذبات + طيف في الوقت الفعلي، أو مخطط طيفي شلالي
- **الوضع الغامر** : تشغيل بملء الشاشة مع كلمات كاريوكي وتكبير الخط

## البناء (macOS 13+، يتطلب Xcode CLT / Swift 6)

```bash
cd macos
make            # بناء release + حزمة FreePlayer.app
make run        # تشغيل بناء التصحيح مباشرة
make run-app    # فتح التطبيق المجمّع
make test       # تشغيل اختبارات الوحدة
```

## قاعدة البيانات

SQLite في ~/Library/Application Support/FreePlayer/library.db:

- tracks — المقاطع (replaygain، play_count، last_played_at، lrc_path، …)
- play_history — سجل التشغيل
- playlists / playlist_tracks — قوائم التشغيل ومقاطعها
- settings — إعدادات مفتاح-قيمة
