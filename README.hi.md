# FreePlayer (macOS)

लोकल म्यूज़िक प्लेयर। नेटवर्क नहीं, लॉगिन नहीं, डेटा संग्रह नहीं। आपका संगीत आपकी हार्ड डिस्क पर, आपकी अपनी फ़ोल्डर संरचना में।

नेटिव macOS (SwiftUI + AppKit) कार्यान्वयन, बिना तीसरे पक्ष की रनटाइम निर्भरता (केवल सिस्टम फ्रेमवर्क + SQLite)।

## समर्थित प्रारूप

MP3, FLAC, WAV, OGG, M4A, AAC, AIFF (AVFoundation द्वारा डिकोड योग्य)

## मुख्य विशेषताएँ

- **आयात और लाइब्रेरी** : आयात करते समय मेटाडेटा स्वचालित रूप से पढ़ा जाता है (शीर्षक, कलाकार, एल्बम, वर्ष, शैली, ट्रैक संख्या, बिटरेट, सैंपल दर, चैनल); फ़ाइलें कलाकार/एल्बम संरचना में कॉपी या सिमलिंक होती हैं (सेटिंग्स में मोड चुनें)
- **सुनने के आँकड़े** : हर सत्र SQLite में दर्ज होता है (आरंभ/अंत, अवधि, प्रतिशत) — कुल समय, चलाने की संख्या, शीर्ष 10 गाने/कलाकार, पिछले 30 दिनों के दैनिक आँकड़े
- **प्लेलिस्ट** : बनाना/नाम बदलना/हटाना, एकल या बैच जोड़ना, सूची संपादन
- **LRC बोल** : .lrc फ़ाइलों का स्वतः पता लगाना या मैनुअल जोड़; एन्कोडिंग फ़ॉलबैक UTF-8 → GB18030 → Shift_JIS
- **ReplayGain** : फ़ाइल टैग से वॉल्यूम स्वचालित समायोजन
- **कवर** : आयात करते समय एम्बेडेड आर्टवर्क निकालकर एल्बम के .covers फ़ोल्डर में संग्रहीत
- **मीडिया कुंजियाँ / मेनू बार** : सिस्टम प्ले/पॉज़·पिछला·अगला कुंजियाँ, Control Center में ट्रैक जानकारी, मेनू बार ट्रे से नियंत्रण; विंडो बंद करने पर ट्रे में छिपकर प्लेबैक जारी
- **विज़ुअलाइज़र** : रीयल-टाइम वेवफॉर्म (ऑसिलोस्कोप + स्पेक्ट्रम) या स्पेक्ट्रोग्राम वॉटरफ़ॉल
- **इमर्सिव मोड** : फ़ुल-स्क्रीन बिना विचलित हुए प्लेबैक, काराओके बोल और फ़ॉन्ट स्केलिंग के साथ

## निर्माण (macOS 13+, Xcode CLT / Swift 6 आवश्यक)

```bash
cd macos
make            # release बिल्ड + FreePlayer.app पैकेज
make run        # डिबग बिल्ड सीधे चलाएँ
make run-app    # पैकेज किया गया ऐप खोलें
make test       # यूनिट टेस्ट चलाएँ
```

## डेटाबेस

SQLite, ~/Library/Application Support/FreePlayer/library.db पर:

- tracks — ट्रैक (replaygain, play_count, last_played_at, lrc_path, …)
- play_history — सुनने का इतिहास
- playlists / playlist_tracks — प्लेलिस्ट और उनके ट्रैक
- settings — कुंजी-मान सेटिंग्स
