# FreePlayer (Android)

लोकल म्यूज़िक प्लेयर। नेटवर्क नहीं, लॉगिन नहीं, डेटा संग्रह नहीं। आपका संगीत आपके डिवाइस पर, आपकी अपनी फ़ोल्डर संरचना में।

> macOS (SwiftUI) संस्करण रिपॉज़िटरी के `Swift` ब्रांच में है; पुराना वेब संस्करण `master` में है।

## समर्थित प्रारूप

MP3, FLAC, WAV, OGG, M4A, AAC, OPUS, MP4 (सिस्टम डिकोडर की सीमा के अनुसार)

## मुख्य विशेषताएँ

- **आयात और साझा**: सिस्टम फ़ाइल चयनकर्ता से फ़ोल्डर आयात करें; अन्य ऐप्स (WeChat, फ़ाइल प्रबंधक आदि) से साझा किया गया ऑडियो "FreePlayer से खोलें" से एक टैप में आयात होता है
- **लाइब्रेरी**: मेटाडेटा का स्वचालित निष्कर्षण (शीर्षक, कलाकार, एल्बम, वर्ष, शैली, ट्रैक संख्या, बिटरेट, सैंपल दर, चैनल), कलाकार/एल्बम संरचना में संग्रहीत, एम्बेडेड कवर के साथ
- **सुनने के आँकड़े**: हर बार चलाने पर रिकॉर्ड (आरंभ/अंत, अवधि, प्रतिशत) — कुल समय, चलाने की संख्या, शीर्ष 10 गाने/कलाकार, पिछले 30 दिनों के दैनिक आँकड़े
- **प्लेलिस्ट**: बनाना/नाम बदलना/हटाना, एकल या बैच जोड़ना, सूची संपादन
- **LRC बोल**: .lrc फ़ाइलों का स्वतः पता लगाना या मैनुअल जोड़; एन्कोडिंग फ़ॉलबैक UTF-8 → GB18030 → Shift_JIS
- **ReplayGain**: वॉल्यूम का स्वचालित समायोजन
- **विज़ुअलाइज़र**: ऑसिलोस्कोप + स्पेक्ट्रम + स्पेक्ट्रोग्राम वॉटरफ़ॉल
- **इमर्सिव मोड**: फ़ुल-स्क्रीन बिना विचलित हुए प्लेबैक
- **मीडिया कुंजियाँ / सूचना**: फ़ोरग्राउंड सेवा सूचना से नियंत्रण; लॉक स्क्रीन और ब्लूटूथ हेडफ़ोन पर काम करता है

## निर्माण

Android SDK आवश्यक (compileSdk 37, minSdk 26)।

```bash
cd Android
./gradlew :app:assembleDebug     # डिबग APK
./gradlew :app:assembleRelease   # रिलीज़ APK (हस्ताक्षर कॉन्फ़िगरेशन चाहिए)
./gradlew :app:testDebugUnitTest # यूनिट टेस्ट
```

रिलीज़ हस्ताक्षर: `freeplayer-release.jks` और `keystore.properties` (storeFile/storePassword/keyAlias/keyPassword) को `Android/` में रखें; यह फ़ाइल git में अनदेखी की जाती है और कभी कमिट नहीं होती।

## डेटाबेस

SQLite, ऐप के निजी डेटा निर्देशिका में:

- tracks — ट्रैक (replaygain, lrc_path, …)
- play_history — सुनने का इतिहास
- playlists / playlist_tracks — प्लेलिस्ट और उनके ट्रैक
- settings — कुंजी-मान सेटिंग्स
