# FreePlayer (Android)

Локальный музыкальный плеер. Без сети, без входа в аккаунт, без сбора данных. Ваша музыка остаётся на вашем устройстве в вашей собственной структуре папок.

> Реализация для macOS (SwiftUI) доступна в ветке `Swift`; старая веб-версия — в ветке `master`.

## Поддерживаемые форматы

MP3, FLAC, WAV, OGG, M4A, AAC, OPUS, MP4 (в пределах системных декодеров)

## Возможности

- **Импорт и шеринг**: импорт папок через системный выбор файлов; аудио, переданное из других приложений (WeChat, файловые менеджеры…), импортируется одним касанием через «Открыть с помощью FreePlayer»
- **Библиотека**: автоматическое извлечение метаданных (название, исполнитель, альбом, год, жанр, трек, битрейт, частота, каналы), хранение в структуре Исполнитель/Альбом со встроенными обложками
- **Статистика прослушивания**: каждая сессия записывается (начало/конец, длительность, процент) — общее время, число воспроизведений, Топ-10 треков/исполнителей, дневная статистика за 30 дней
- **Плейлисты**: создание/переименование/удаление, добавление по одному или пачкой, редактирование списка
- **Тексты LRC**: автодетекция или ручное связывание файлов .lrc; кодировки UTF-8 → GB18030 → Shift_JIS
- **ReplayGain**: автоматическая регулировка громкости
- **Визуализатор**: осциллограф + спектр + спектрограмма-водопад
- **Иммерсивный режим**: полноэкранное воспроизведение без отвлекающих элементов
- **Медиа-клавиши / уведомление**: управление через уведомление фонового сервиса; работает на экране блокировки и с Bluetooth-наушниками

## Сборка

Требуется Android SDK (compileSdk 37, minSdk 26).

```bash
cd Android
./gradlew :app:assembleDebug     # debug-APK
./gradlew :app:assembleRelease   # release-APK (нужна конфигурация подписи)
./gradlew :app:testDebugUnitTest # юнит-тесты
```

Подпись релиза: поместите `freeplayer-release.jks` и `keystore.properties` (storeFile/storePassword/keyAlias/keyPassword) в `Android/`; файл игнорируется git и никогда не коммитится.

## База данных

SQLite, в приватном каталоге данных приложения:

- tracks — треки (replaygain, lrc_path, …)
- play_history — история прослушивания
- playlists / playlist_tracks — плейлисты и треки
- settings — настройки «ключ-значение»
