# FreePlayer (macOS)

Локальный музыкальный плеер. Без сети, без входа в аккаунт, без сбора данных. Ваша музыка остаётся на вашем диске, в вашей собственной структуре папок.

Нативная реализация для macOS (SwiftUI + AppKit), без сторонних зависимостей (только системные фреймворки + SQLite).

## Поддерживаемые форматы

MP3, FLAC, WAV, OGG, M4A, AAC, AIFF (декодируются AVFoundation)

## Возможности

- **Импорт и библиотека** : автоматическое извлечение метаданных (название, исполнитель, альбом, год, жанр, трек, битрейт, частота, каналы); файлы копируются или линкуются в структуру Исполнитель/Альбом (режим выбирается в настройках)
- **Статистика прослушивания** : каждая сессия записывается в SQLite (начало/конец, длительность, процент) — общее время, воспроизведения, Топ-10 треков/исполнителей, дневная статистика за 30 дней
- **Плейлисты** : создание/переименование/удаление, добавление по одному или пачкой, редактирование
- **Тексты LRC** : автодетекция или ручное связывание файлов .lrc; кодировки UTF-8 → GB18030 → Shift_JIS
- **ReplayGain** : автоматическая регулировка громкости по тегам
- **Обложки** : встроенные изображения извлекаются при импорте в папку .covers альбома
- **Медиа-клавиши / строка меню** : системные клавиши play/pause/предыдущий/следующий, информация в Control Center, управление через иконку в строке меню; закрытие окна сворачивает его в строку меню и продолжает воспроизведение
- **Визуализатор** : осциллограф + спектр в реальном времени или спектрограмма-водопад
- **Иммерсивный режим** : полноэкранное воспроизведение с караоке-текстами и масштабированием шрифта

## Сборка (macOS 13+, Xcode CLT / Swift 6)

```bash
cd macos
make            # release-сборка + пакет FreePlayer.app
make run        # запустить debug-сборку напрямую
make run-app    # открыть собранное приложение
make test       # запустить юнит-тесты
```

## База данных

SQLite в ~/Library/Application Support/FreePlayer/library.db :

- tracks — треки (replaygain, play_count, last_played_at, lrc_path, …)
- play_history — история прослушивания
- playlists / playlist_tracks — плейлисты и треки
- settings — настройки «ключ-значение»
